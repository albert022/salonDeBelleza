# Aura Beauty Studio — Salón de Belleza | QRMOON

Página web profesional y de alta conversión para salón de belleza y estética en **Santo Domingo, República Dominicana**, con integración directa a WhatsApp oficial de **QRMOON**.

---

## 💎 Identidad Visual y Conceptual

- **Nombre:** Aura Beauty Studio
- **Ubicación:** Piantini, Santo Domingo, Distrito Nacional, República Dominicana.
- **Moneda:** Pesos Dominicanos (`RD$`).
- **Paleta de colores:** Crema (`#FCFAF6`), Rosa empolvado (`#DEAFB4` / `#B86B74`), Blanco, Marrón suave / Taupe (`#3D322C`), y Acentos dorados (`#C9A74E`).
- **Tipografías:** *Cormorant Garamond* y *Montserrat*.

---

## 📲 Integración Oficial con WhatsApp

- **Teléfono y WhatsApp:** `+1 829 499 4321` (`wa.me/18294994321`)
- **Mensaje establecido para toda la web con rastreo de origen:**
  > **"¡Hola! Quisiera solicitar una cotización y saber más detalles del servicio. (QRMOON) (Aura Beauty Studio - [Origen del Clic])"**

Todos los botones de acción, tarjetas de servicios, modal de galería, formulario de contacto, asistente virtual FAQ, botón flotante y código QR están configurados para enviar este mensaje identificando la sección de procedencia.

---

## 🏗️ Arquitectura de la Solución (3 Secciones Principales)

### 1. Inicio y Servicios (`#inicio`)
- **Hero Principal:** Fotografía de impacto, propuesta de valor *"Realzamos tu belleza, resaltamos tu esencia"*, botones de WhatsApp y exploración de servicios, e insignia de Google Reviews (4.9 estrellas).
- **Servicios:** 6 tarjetas interactivas:
  1. *Cortes & Peinados*
  2. *Coloración & Tratamientos Capilares*
  3. *Manicura & Pedicura Spa*
  4. *Maquillaje Profesional*
  5. *Diseño de Cejas & Pestañas*
  6. *Tratamientos Faciales*
  - Cada servicio incluye duración, descripción, nota informativa y botón **"Consultar precio"** que abre WhatsApp.
- **Por qué elegirnos:** *Atención Personalizada*, *Productos de Calidad* y *Profesionales Capacitados*.

### 2. Trabajos Realizados (`#trabajos`)
- **Galería Profesional con Filtros:** Filtros dinámicos (*Todos*, *Cabello & Color*, *Uñas*, *Maquillaje*, *Cejas & Pestañas*, *Faciales*).
- **Lightbox / Modal Ampliado:** Visor en alta resolución con descripción y botón directo a WhatsApp.
- **Testimonios:** Bloque visual de opiniones verificadas con enlace oficial a Google Reviews.
- **Llamado a la Acción (CTA Banner):** *"¿Te gustaría un resultado así? Escríbenos por WhatsApp"*.

### 3. Contacto y Cotizaciones (`#contacto`)
- **Formulario de Cotización con Validación:** Campos obligatorios (*Nombre*, *WhatsApp con prefijo dominicano +1 829 499 4321*, *Servicio de interés* y *Mensaje*).
- **Información del Negocio:** Dirección física en Piantini, enlace a Google Maps, horarios de atención y redes sociales (Instagram, TikTok).
- **Tarjeta de Contacto Directo:**
  - Código QR generado dinámicamente para abrir WhatsApp al instante.
  - Pestaña para escanear y calificar en Google Reviews.
  - Botones de acción directa a WhatsApp y llamada.

---

## ⚡ Funcionalidades Globales

- **Botón Flotante de WhatsApp:** Visible en la esquina inferior derecha con indicador de pulso y acceso inmediato.
- **Asistente FAQ / Chatbot Básico:** Widget interactivo con 5 consultas frecuentes y botón de WhatsApp.
- **SEO & Rendimiento:** Open Graph, datos estructurados Schema.org (`BeautySalon`), semántica HTML5 y compatibilidad con Google Analytics.

## 🚀 Puesta en Marcha Local

```bash
# 1. Instalar dependencias
npm install

# 2. Compilar para producción
npm run build

# 3. Iniciar servidor
npm run start
```

Disponible en `http://localhost:3000`.
